ALIGNHSC COMPLETE REVIEW KIT (OPTIONAL DOTPOINTS)

1. Open folder alignhsc-review-kit in VS Code and open review.html with Live Server.
2. Review all original question AND solution crops. You can approve without choosing syllabus dotpoints.
3. Save review JSON to keep your work (do not overwrite/delete that exported JSON).
4. Optional: Copy syllabus.js from your main alignhsc website into alignhsc-review-kit if you want the optional dotpoint picker.
5. The website-update-optional/script.js file is NOT for the review kit. Only use it to replace the main website script.js after making a backup and confirming it matches your current version. It allows topic fallback for untagged questions.
6. Export approved-questions.js from review.html. It does not automatically merge with website questions.js; approved images must also be copied to the public questions/ and solutions/ folders.
7. This is a local REVIEW tool, not an autonomous background AI agent. All crops are provisional; check for clipped math and handwritten solution quality. Verify permission before publishing.
